# Headed-In

**Headed-In** ist ein Unity-Spiel, das ein S-Shooting-Szenario darstellt.

## Beschreibung

Headed-In ist ein Spiel, das in einer Schule Der Fokus liegt auf Atmosphäre, Spannung und Interaktion innerhalb der Spielwelt.


## Technologien

* Unity Engine
* C#
* Standard Unity Packages

## Projektstruktur

```
Assets/
Packages/
ProjectSettings/
```

## Installation

1. Repository klonen:

   ```bash
   git clone https://github.com/NuIIskill/Headed-In.git
   ```
2. Projekt in Unity Hub öffnen
3. Passende Unity-Version auswählen
4. Starten
