# Headed-In

**Headed-In** ist ein Unity-Spiel, das ein S-Shooting-Szenario darstellt.

## Beschreibung

Headed-In ist ein Spiel, das in einer Schule spielt und ein School Shooting als zentrales Szenario thematisiert. Der Fokus liegt auf Atmosphäre, Spannung und Interaktion innerhalb der Spielwelt.

## Hinweis

Dieses Projekt behandelt ein äußerst sensibles und reales Thema. Es ist nicht dazu gedacht, Gewalt zu verherrlichen oder zu fördern. Der Inhalt sollte mit entsprechendem Bewusstsein und Kontext betrachtet werden.

## Technologien

* Unity Engine
* C#
* Standard Unity Packages

## Installation

1. Repository klonen:

   ```bash
   git clone https://github.com/NuIIskill/Headed-In.git
   ```
2. Projekt in Unity Hub öffnen
3. Passende Unity-Version auswählen
4. Starten
